Mercado Livre

API oficial (recomendado)

O ML bloqueia a leitura do site por robôs. Crie um aplicativo em developers.mercadolivre.com.br e informe as credenciais para buscar pela API oficial.

Amazon

Programa: associados.amazon.com.br. Sua tag aparece no topo do painel de associados (ex.: ofertou-20).

Shopee

Programa: affiliate.shopee.com.br → Open API. Sem estas credenciais a Shopee não é minerada (ela bloqueia robôs). Os links gerados pela API já contêm sua comissão.

Sem a Open API, as ofertas da Shopee cadastradas manualmente saem com este ID no link. A mineração automática só funciona com App ID + Senha.

AliExpress

Programa: portals.aliexpress.com → Open Platform. Com as credenciais, a mineração usa a API oficial e gera links com comissão; sem elas, lê a busca pública (links sem comissão).

KaBuM!

  1. Cadastre-se no programa de afiliados da KaBuM!.
  2. Gere o link de afiliado de qualquer produto.
  3. Cole esse link aqui e salve.

Magalu

Programa Parceiro Magalu / Magazine Você. Cole o link da sua loja (ex.: magazinevoce.com.br/magazinesualoja) ou só o nome. Com ele, o site minera as ofertas da Magalu automaticamente pela sua loja e todos os links já saem com a sua comissão.

Postagem automática nas redes sociais

Na página de ofertas, toque no ✓ de um produto para levá-lo à tela Postagens. Lá você edita os textos, publica manualmente ou clica em Postar automaticamente nas redes marcadas. Usuários do site só usam essa tela se você liberar em Usuários → Gerenciar → Permitir postagens nas redes; eles publicam nas contas configuradas aqui.

O WhatsApp não tem API oficial para grupos: a postagem automática usa um número separado conectado pela Z-API ou pela Evolution API (configure abaixo). O botão manual de WhatsApp continua disponível em cada produto.

Marca d'água nas imagens

As fotos das postagens vão num quadrado 1080×1080 com o selo do site (a Capi + o nome e, se houver, o endereço público do site). Vale para WhatsApp, Telegram, Facebook e para o "Baixar imagem" da tela de postagens. No Instagram, só depois que o site tiver endereço público (VPS), porque ele baixa a foto pelo endereço.

WhatsApp (número separado para as postagens)

O WhatsApp não tem API oficial para grupos. A postagem automática usa um serviço que conecta um número ao WhatsApp Web: Z-API (pago, na nuvem, funciona sem servidor) ou Evolution API (grátis, roda no seu computador ou VPS com Docker). Use um número só para isso: o WhatsApp pode banir números automatizados. Para reduzir o risco, use um chip com algumas semanas de uso, mantenha o intervalo entre mensagens e poste só em grupos onde as pessoas entraram por vontade própria.

Na Z-API: crie uma instância, leia o QR code com o WhatsApp do número separado e copie o ID e o token da instância. O "token de segurança da conta" fica em Segurança (obrigatório se estiver ativado).

Na Evolution API (v2): crie uma instância, leia o QR code com o WhatsApp do número separado e informe aqui o endereço, a chave global (AUTHENTICATION_API_KEY) e o nome da instância.

Grupos de destino

Marque os grupos que vão receber as postagens. O número precisa ser membro (de preferência administrador) de cada grupo.

Postagens agendadas

Nos horários abaixo (horário de Brasília), o site publica algumas ofertas nas redes marcadas: primeiro as da fila (botão "Adicionar à fila agendada" na tela de postagens) e, se faltar, as melhores ofertas do momento (maior desconto, categorias variadas, sem repetir o que foi postado nos últimos 7 dias). Funciona enquanto o site estiver ligado (no seu computador ou na VPS); não roda na Vercel.

Facebook e Instagram

  1. Você precisa de uma Página do Facebook e, para o Instagram, de uma conta profissional (comercial ou criador) ligada a essa página.
  2. Em developers.facebook.com, crie um app do tipo Empresa e adicione os produtos Facebook Login para Empresas e API do Instagram.
  3. No Explorador da API do Graph, gere um token com as permissões pages_manage_posts, pages_read_engagement, instagram_basic e instagram_content_publish, e troque por um token de página de longa duração.
  4. ID da página: em Página → Sobre → Transparência da página. ID do Instagram: consulte /{id-da-página}?fields=instagram_business_account no Explorador.

O Instagram só publica com foto, e a foto precisa estar num endereço público (as fotos das lojas já estão). Links no texto do Instagram não são clicáveis.

X (Twitter)

  1. Em developer.x.com, crie um projeto e um app.
  2. Em User authentication settings, ative OAuth 1.0a com permissão Read and write.
  3. Em Keys and tokens, copie a API Key e o API Key Secret, e gere o Access Token e o Access Token Secret (gere depois de ativar a escrita).

No X o texto é resumido automaticamente (nome, preço e link) para caber em 280 caracteres.

Google AdSense (anúncios do Google)

Os espaços sem campanha de anunciante passam a mostrar anúncios do Google, e você recebe pelo AdSense. As campanhas das empresas que você cadastrar abaixo continuam com prioridade. Dentro do app das lojas os anúncios do Google não aparecem (regra do AdSense).

  1. Crie a conta em adsense.google.com com o domínio do site (ex.: ofertou.com.br — precisa estar no ar com https).
  2. Copie o ID de editor (Conta → Informações da conta, começa com ca-pub-), cole abaixo e salve. O site já coloca sozinho o código de verificação nas páginas e o arquivo /ads.txt.
  3. No AdSense, peça a análise do site. A aprovação costuma levar de alguns dias a 2 semanas.
  4. Depois de aprovado: Anúncios → Por bloco de anúncios → crie um bloco de display para cada espaço e cole o número do data-ad-slot de cada um abaixo. Ligue "Mostrar anúncios do Google".

Os pagamentos do AdSense são feitos pelo Google direto na sua conta bancária, quando o saldo passa do mínimo (cerca de R$ 100). Configure os dados de pagamento e de impostos no próprio AdSense.
