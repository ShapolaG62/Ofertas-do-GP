Links de afiliado

Ao salvar, todos os links das ofertas existentes são atualizados. Campos de senha/segredo ficam guardados no servidor e nunca são exibidos de novo: deixe em branco para manter o valor atual.

Mercado Livre

Programa: mercadolivre.com.br/afiliados. Confira no gerador de links do programa os valores de matt_word e matt_tool do seu link e teste um link gerado aqui antes de divulgar.

API oficial (recomendado)

O ML bloqueia a leitura do site por robôs. Crie um aplicativo em developers.mercadolivre.com.br e informe as credenciais para buscar pela API oficial.

Amazon

Programa: associados.amazon.com.br. Sua tag aparece no topo do painel de associados (ex.: ofertasdogp-20).

Shopee

Programa: affiliate.shopee.com.br → Open API. Sem estas credenciais a Shopee não é minerada (ela bloqueia robôs). Os links gerados pela API já contêm sua comissão.

AliExpress

Programa: portals.aliexpress.com → Open Platform. Com as credenciais, a mineração usa a API oficial e gera links com comissão; sem elas, lê a busca pública (links sem comissão).

Magalu

Programa Parceiro Magalu / Magazine Você. Informe o nome da sua loja (o que vem depois de magazinevoce.com.br/magazine). Links da Magalu cadastrados manualmente serão convertidos.

Shein e Temu

Não há API pública de produtos. Gere o link de afiliado no painel do programa de cada loja e cole no campo "Seu link de afiliado" ao cadastrar a oferta manualmente.
